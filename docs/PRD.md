\# GuroMate — Product Requirements Document



\## 1. Overview



GuroMate is a teacher-assist web application designed to help Filipino elementary teachers create and manage lesson plans more efficiently.



\## 2. Problem



Teachers spend significant time preparing, formatting, and aligning lesson plans with curriculum requirements.



GuroMate aims to reduce this workload through templates, guided inputs, and reusable teaching resources.



\## 3. Target Users



\- Filipino elementary teachers

\- Public and private school teachers

\- Teachers with limited or inconsistent internet access



\## 4. MVP Features



\- Lesson Plan Builder

\- DepEd-aligned ILAW template

\- Grade and subject selection

\- Local/offline plan storage

\- Resource library

\- PDF/DOC export

\- Filipino/English interface



\## 5. Proposed Technology



\- Frontend: React

\- Architecture: Progressive Web App (PWA)

\- Local Storage: IndexedDB

\- Version Control: Git + GitHub



\## 6. Initial User Flow



1\. Open GuroMate

2\. Select grade and subject

3\. Choose a lesson template

4\. Fill in lesson details

5\. Save the lesson plan

6\. Export the finished plan



\## 7. Future Features



\- AI-assisted suggestions

\- More curriculum resources

\- Cloud synchronization

\- Teacher collaboration

\- Additional lesson templates
